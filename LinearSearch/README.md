# Linear Search

This project demonstrates the **Linear Search algorithm** for finding a target element in an array.

The algorithm checks each element of the array one by one from the beginning until the target element is found or the end of the array is reached.

## How It Works

1. Start from the first element of the array.
2. Compare each element with the target.
3. If the element matches the target, return its index.
4. If the target is not found after checking all elements, report that it is not present.

## Complexity

* **Best Case:** O(1)
* **Average Case:** O(n)
* **Worst Case:** O(n)
* **Space Complexity:** O(1)

## Main Concept

**Sequential Search Algorithm**
