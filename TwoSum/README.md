# Two Sum

This project demonstrates a **Brute-Force Two Sum algorithm** for finding two elements in an array whose sum is equal to a given target.

The algorithm checks every possible pair of elements and prints the index of the first element when a matching pair is found.

## How It Works

1. Go through every possible pair of elements in the array.
2. Add the two elements together.
3. Compare their sum with the target value.
4. If the sum equals the target, print the index of the first element.
5. Continue until a matching pair is found.

For example:

```text
Array: [0, 7, 11, 2]
Target: 9

7 + 2 = 9
