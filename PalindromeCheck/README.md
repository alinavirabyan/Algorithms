# Palindrome Check

This project demonstrates how to check whether a given word is a **palindrome**.

A palindrome is a word that reads the same forward and backward. The program reverses the input word and compares it with the original word.

## How It Works

1. Read a word from the user.
2. Reverse the word.
3. Compare the original word with its reversed version.
4. If they are equal, the word is a palindrome.
5. Otherwise, the word is not a palindrome.

## Complexity

* **Time Complexity:** O(n)
* **Space Complexity:** O(n)

where `n` is the length of the word.
