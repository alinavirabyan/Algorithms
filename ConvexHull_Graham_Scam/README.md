# Graham Scan — Convex Hull

## Description

**Graham Scan** is a computational geometry algorithm used to find the **convex hull** of a set of 2D points. It finds the outermost points and forms the smallest convex polygon around them.

## Project

This Python project:

* Generates 35 random points
* Finds the convex hull using Graham Scan
* Visualizes the result with Matplotlib

## Technologies

* Python
* Matplotlib

## Installation

```bash
pip install matplotlib
```

## Run

```bash
python graham_scan.py
```

🔵 Blue points represent the generated points.
🔴 Red boundary represents the convex hull.
