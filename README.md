# Algorithms

A collection of algorithm implementations in Python covering searching, sorting, string processing, matrix operations, graph algorithms, computational geometry, and common algorithmic problems.

This repository was created to practice algorithmic thinking, understand fundamental computer science concepts, and build a collection of implementations that can be referenced for future projects and studies.

---

## 📚 Algorithms

### 🔎 Searching Algorithms

| Algorithm | Description |
|---|---|
| [Binary Search](https://github.com/alinavirabyan/Algorithms/tree/main/BinarySearch) | Searches for an element in a sorted array by repeatedly dividing the search interval in half. |
| [Linear Search](https://github.com/alinavirabyan/Algorithms/tree/main/LinearSearch) | Sequentially checks each element until the target is found. |
| [Jump Search](https://github.com/alinavirabyan/Algorithms/tree/main/JumpSearch) | Searches a sorted array by jumping through blocks and then performing a linear search. |
| [Interpolation Search](https://github.com/alinavirabyan/Algorithms/tree/main/InterpolationSearch) | Estimates the probable position of a target in a uniformly distributed sorted array. |
| [Exponential Search](https://github.com/alinavirabyan/Algorithms/tree/main/ExponentialSearch) | Finds a search range by exponentially increasing the index before applying binary search. |
| [Ternary Search](https://github.com/alinavirabyan/Algorithms/tree/main/TernarySearch) | Divides a sorted search range into three parts instead of two. |

---

### 🔢 Sorting Algorithms

| Algorithm | Description |
|---|---|
| [Bubble Sort](https://github.com/alinavirabyan/Algorithms/tree/main/BubbleSort) | Repeatedly compares adjacent elements and swaps them when they are in the wrong order. |
| [Insertion Sort](https://github.com/alinavirabyan/Algorithms/tree/main/InsertionSort) | Builds the sorted array one element at a time by inserting elements into their correct position. |
| [Shell Sort](https://github.com/alinavirabyan/Algorithms/tree/main/ShellSort) | An improved version of insertion sort that compares elements separated by a gap. |
| [Quick Sort](https://github.com/alinavirabyan/Algorithms/tree/main/QuickSort) | Uses a pivot and recursively partitions the array into smaller and larger elements. |
| [Merge Sort](https://github.com/alinavirabyan/Algorithms/tree/main/MergeSort) | Uses divide-and-conquer to divide, sort, and merge arrays. |
| [Heap Sort](https://github.com/alinavirabyan/Algorithms/tree/main/HeapSort) | Uses a binary heap to repeatedly extract the largest element. |

### 🔤 String Algorithms

| Algorithm | Description |
|---|---|
| [Naive String Matching](https://github.com/alinavirabyan/Algorithms/tree/main/NaiveStringMatching) | Checks every possible position of a pattern in a text. |
| [Knuth-Morris-Pratt (KMP)](https://github.com/alinavirabyan/Algorithms/tree/main/KnuthMorrisPratt) | Uses a prefix table to avoid unnecessary comparisons during pattern matching. |
| [Boyer-Moore String Search](https://github.com/alinavirabyan/Algorithms/tree/main/BoyerMooreStringSearch) | Searches from right to left and uses character-based shifts to skip comparisons. |
| [Finite Automaton Pattern Matching](https://github.com/alinavirabyan/Algorithms/tree/main/FiniteAutomatonPatternMatching) | Uses a finite automaton to process text and detect occurrences of a pattern. |
| [Palindrome Check](https://github.com/alinavirabyan/Algorithms/tree/main/PalindromeCheck) | Determines whether a string reads the same forward and backward. |
| [Palindrome Generator](https://github.com/alinavirabyan/Algorithms/tree/main/PalindromeGenerator) | Constructs a palindrome from the characters of a given string. |
| [Longest Palindromic Substring](https://github.com/alinavirabyan/Algorithms/tree/main/LongestPalindromicSubstring) | Finds the longest substring that is a palindrome. |

## 📈 Complexity

The repository contains algorithms with different computational complexities, including:

- **O(1)** — Constant
- **O(log n)** — Logarithmic
- **O(n)** — Linear
- **O(n log n)** — Linearithmic
- **O(n²)** — Quadratic
- **O(n³)** — Cubic
- **O(n²·⁸⁰⁷)** — Strassen Matrix Multiplication

Each algorithm's individual directory contains a README with its description, main concept, and complexity analysis.
