# Finite Automaton Pattern Matching

This project demonstrates **pattern matching using a finite automaton**.

The algorithm builds a transition table based on the pattern and then processes the text character by character. When the automaton reaches the final state, the pattern has been found in the text.

**Main Concept:** Finite Automata and String Pattern Matching

**Time Complexity:** O(n × m + n), where `n` is the text length and `m` is the pattern length.
