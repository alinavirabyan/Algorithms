# Matrix Multiplication

This project demonstrates **Matrix Multiplication** using three nested loops.

The algorithm multiplies two matrices by taking the elements of each row from the first matrix and multiplying them by the corresponding elements of each column from the second matrix.

## How It Works

1. Create two matrices.
2. Create an empty matrix for the result.
3. Iterate through the rows of the first matrix.
4. Iterate through the columns of the second matrix.
5. Multiply corresponding elements and add them to calculate each result element.
6. Store the result in the new matrix.

## Complexity

- **Time Complexity:** O(n³)
- **Space Complexity:** O(n²)

## Main Concept

**Matrix Operations / Nested Loops**
